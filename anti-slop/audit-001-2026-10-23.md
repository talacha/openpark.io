# OpenPark app audit 001

Date: 2026-10-23
Scope: `apps/web` after the Shadcn Base UI migration. The API and marketing surfaces were reviewed for boundaries and left unchanged.

Design read: operations PWA for parking staff, administrators, and residents, using OpenPark's existing neutral and green visual language. Dials: ENERGY 1 / RHYTHM 1 / MOTION 1. The sidebar supports wayfinding, cards group related tasks and metrics, system typography prioritizes dense operational readability, spacing follows the existing token scale, and occupancy patterns communicate state rather than decorate.

## Findings

1. **FIXED — HIGH, R-03, mobile tap targets:** shared buttons, icon buttons, inputs, and selects now have a 44 px minimum target (`apps/web/src/styles.css`, `apps/web/src/components/ui/button.tsx`, `input.tsx`, `native-select.tsx`).
2. **FIXED — HIGH, R-25, warning-text contrast:** light-theme warning text is now `#a34b07`, measuring 5.24:1 against the warning surface (`apps/web/src/styles.css`).
3. **FIXED — HIGH, R-25, control-boundary contrast:** controls use `--control-border`; rendered boundaries measure 4.52:1 in light mode and 5.05:1 in dark mode (`apps/web/src/styles.css`, `apps/web/src/components/ui/input.tsx`, `apps/web/src/components/ui/native-select.tsx`).
4. **FIXED — HIGH, R-32, keyboard access:** session timelines have a native button supporting Enter and Space, while row clicks remain available (`apps/web/src/screens/Sessions.tsx`).
5. **FIXED — HIGH, R-27, asynchronous UI states:** `QueryState` supplies consistent loading, empty, and error states across the affected data views. Rates now exposes request failures instead of remaining on its loading message (`apps/web/src/components/QueryState.tsx`, `apps/web/src/screens/Rates.tsx`).
6. **FIXED — HIGH, R-02, copy punctuation:** attendant missing-value placeholders use localized `common.none` (`apps/web/src/screens/Attendant.tsx`).
7. **FIXED — LOW, R-31, comment hygiene:** decorative dashed section-banner comments were removed from the attendant screen (`apps/web/src/screens/Attendant.tsx`).

Findings 1–7 were approved and fixed on 2026-10-23.
