# OpenPark app audit 002 — fix follow-up

Date: 2026-10-25
Follows: `anti-slop/audit-002-2026-10-25.md`
Scope: the 9 findings approved on 2026-10-25 for the resident surface. All 9 are fixed.

## Fixed findings

1. **FIXED — HIGH, R-02, terminology drift.** The destination and the screen now share one name: `nav.parkingPasses` and `res.title` are "Parking passes" in `en.json`, with the localized equivalent in every source locale; `res.noUnitAdmin` now says "this screen" instead of "the resident view". `en-XA.json` was regenerated with `scripts/pseudo.mjs`; docs, menu test descriptions, and the e2e expectation were aligned. The object remains a "guest pass" (`res.sectionNew`, `res.sectionCurrent`).
2. **FIXED — HIGH, R-02, R-05, C-3, hidden active pass.** `Resident.tsx` now tracks the last auto-opened pass id and opens the pass section once per pass, so a plain `/r` login shows the active pass without requiring `#new`. The section title is `res.sectionCurrent` ("Your guest pass") when a pass exists and `res.sectionNew` otherwise. A manual collapse is respected; polling the same pass does not re-open it. Regression test: `opens the pass section and titles it as the current pass when a pass exists`.
3. **FIXED — HIGH, R-27, hidden request states.** `active.error` and `history.error` are rendered as banners above both disclosures, and the inner `QueryState` error output is suppressed to avoid duplicate alerts. The initial active-pass request also shows a localized `role="status"` loading line above the disclosures. Regression tests: `shows a failed pass request above the collapsed sections` and `shows the pass loading state before the first response`.
4. **FIXED — HIGH, R-02, R-17, notification help described the fine policy.** `res.notifyHelp` now reads "Turn this off if you do not want these messages." in every locale; it no longer hardcodes 12 hours or describes a fine. The configurable policy remains in the pass form via `{hours}`. Regression test: `describes the notification toggle instead of the fine policy`.
5. **FIXED — HIGH, R-36, unknown issuer labelled "host".** `res.issuedBy_unknown` is now "Issuer unknown" (and localized equivalents) in every source locale, so a legacy null `created_by` no longer asserts an issuer the data does not have.
6. **FIXED — HIGH, R-32, profile editor focus and relationship.** The pencil has `aria-controls="resident-profile-editor"` while expanded; the editor form carries that id; and both Cancel and Save return focus to `profileHeadRef` when the editor closes. Regression test: `keeps the profile editor relationship and returns focus to the pencil when it closes`.
7. **FIXED — HIGH, R-03, RTL pill centering.** `styles.css` now has `[dir='rtl'] .avatar-pill { transform: translateX(50%); }`. A Playwright/Chrome measurement against the actual stylesheet reports a 0 px center offset in both LTR and RTL (previously -44.63 px in RTL).
8. **FIXED — LOW, R-31, menu label title case.** The English label is now "Parking passes", matching the sentence-case menu; the e2e expectation, docs, and test descriptions use the same casing.
9. **FIXED — LOW, R-31, stale comments.** The disclosure comment in `Resident.tsx` and the deep-link comment in `resident-view.test.tsx` now describe direct/bookmarked links and the actual target; the sidebar delivers only `#new`, while `?edit=1` opens the profile editor.
