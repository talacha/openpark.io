# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

OpenPark is a pnpm monorepo (TypeScript) plus two Python projects. `ARCHITECTURE.md` is the design source of truth; `README.md` has the status table of what is and isn't built.

## Commands

```bash
pnpm install
docker run -d --name openpark-pg -e POSTGRES_USER=openpark -e POSTGRES_PASSWORD=openpark -e POSTGRES_DB=openpark -p 54329:5432 postgres:16-alpine
pnpm --filter @openpark/core build   # REQUIRED before api/sdk typecheck or run: they import core's dist/
pnpm migrate                         # runs as the owner role (ADMIN_DATABASE_URL)
pnpm dev:api | dev:web | dev:marketing   # :3000 / :5173 (proxies /v1) / :4321

pnpm typecheck
pnpm test                            # all packages; api tests need Postgres at :54329 or TEST_ADMIN_URL
pnpm --filter @openpark/api exec vitest run -t "full flow"      # single test by name
pnpm --filter @openpark/core exec vitest run test/fees.test.ts  # single file
pnpm --filter @openpark/web check:css   # fails on physical left/right CSS (RTL guard); add `rtl-ok` to a line to exempt
pnpm e2e        # Playwright via installed Chrome; needs api :3000 + web :5173 running (e2e/marketing.mjs also needs marketing :4321)

# Python (venv at services/alpr/.venv)
pytest services/alpr packages/sdk-py -q
docker compose up -d --build        # needs .env (copy .env.example)
```

## Architecture

- **Tenancy is enforced in Postgres, not app code.** Every tenant table has an RLS policy on `app.tenant_id`. The API connects as the non-owner role `openpark_app`; `Database.withTenant()` (`apps/api/src/db.ts`) opens a transaction and sets the setting per request. Queries made via `Database.raw()` see no tenant rows. Cross-tenant lookups (login memberships, API-key resolve, tenant create) go through `SECURITY DEFINER` functions in `migrations/001_init.sql`. `session_event`, `audit_event` and `rate_plan` are insert-only for the app role via grants; keep it that way (history is append-only, used rate plans are immutable, edits create a new version). New tables need RLS enabled plus a grant.
- **Routes** are declared with `defineRoute` / `definePublicRoute` (`apps/api/src/http.ts`), which also feed the generated OpenAPI doc and handle auth, permission check, tenant transaction, `Idempotency-Key` replay (`idempotent: true`) and post-commit hooks (`after`). Don't register raw Fastify routes for tenant endpoints. Money is integer minor units everywhere.
- **Check-in/out logic** lives in `apps/api/src/services/sessions.ts`; fees come only from server timestamps plus the rate-plan version pinned on the session, computed by `packages/core/src/fees.ts`. Realtime is `pg_notify` -> `EventHub` -> SSE; webhooks are pg-boss jobs using `ADMIN_DATABASE_URL`.
- **`packages/core`** is pure logic shared by the API (fees, plate normalisation, inventory range expansion/diff). The inventory Zod schema, `schemas/inventory/v1.json` and the JSON example in `ARCHITECTURE.md` must agree; `packages/core/test/schema.test.ts` enforces this by parsing the doc.
- **Plate-format registry** (`registry/plates/*.json`) is read by the API at startup and by core tests; the web keypad gets charsets from `GET /v1/plate-regions`.
- **Web app** (`apps/web`): writes go through `write()` in `src/api.ts`, which queues to IndexedDB (`offline.ts`) on network failure and replays with the original idempotency key; 4xx replays land in a supervisor conflict queue. All UI strings are ICU messages in `src/locales/*.json`; `en-XA.json` is generated by `scripts/pseudo.mjs` during build (don't edit). Locale tests require identical keys and placeholders across locales, so add keys to every file. Tenant terminology overrides (`term.*`) layer on top of catalogs.
- **ALPR** (`services/alpr`): FastAPI worker, ONNX engine first, optional VLM fallback; the API proxies `/v1/alpr/read` and only stores the plate crop.
- Marketing (`apps/marketing`) hands a new session to the app via URL fragment (`#token=&tenant=`), consumed in `apps/web/src/main.tsx`.

## Gotchas

- `pnpm-workspace.yaml` uses `allowBuilds` (pnpm 11) to permit esbuild/sharp install scripts.
- Env values that are empty strings are treated as unset (`apps/api/src/config.ts`); compose relies on this.
- In tests, the clock is injected (`buildApp({ now })`) and jobs are disabled (`JOBS_ENABLED=false`).
- nginx (`deploy/nginx.conf`) resolves the API at request time via `DNS_RESOLVER`; keep that when changing the proxy.
